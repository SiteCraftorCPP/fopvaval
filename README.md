# Donor Landing Page

Лендинг для донора с современным дизайном и анимациями.

## Технологии

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка для продакшена

```bash
npm run build
```

## Деплой

Проект можно задеплоить на:
- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages
- Любой статический хостинг

После сборки (`npm run build`) загрузите содержимое папки `dist` на хостинг.
